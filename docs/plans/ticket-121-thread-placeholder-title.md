# Plan: Thread placeholder in the sidebar (GF-15 #121)

## Goal
A new chat shows "New chat" in the sidebar, then its generated title, never the thread UUID. A first turn that the server never persists leaves no placeholder row once the polling window closes. No comment mentions Mastra.

## Assumptions
- No test runner exists (`CLAUDE.md`): the "test" step is the repro script in `docs/bug-reports/ticket-121-thread-placeholder-title.repro.tsx` (SSR render of `ThreadListItem`), run before and after; `pnpm build` is the typecheck. Unconfirmed: no new test framework is added.
- A server row with an empty title (made by the thread gate) also shows "New chat".
- Placeholder is dropped by a timeout of `THREAD_ROW_GRACE_MS + 2 * THREAD_TITLE_POLL_INTERVAL_MS` after RUN_FINISHED, only when the server list still has no row for it. A run that fails without RUN_FINISHED is out of scope.
- "Gone after reload" already holds (the draft lives in memory); the fix is that it also goes away without a reload.
- The wording of the LangChain server: the title is generated by a detached step after the turn (`schedule-thread-title`), and a guard-blocked turn is refused before the thread row exists.

## Steps
1. Test: run the repro script on the unfixed tree (done in the bug report: prints the UUID) and re-run after step 2; it must print "New chat" for cases 1 and 2.
   Files: `docs/bug-reports/ticket-121-thread-placeholder-title.repro.tsx` - Change: none (already written)
2. Code: add `NEW_CHAT_TITLE` to `constants/threads.ts` and a small helper `lib/thread-title.ts` with `isPlaceholderTitle(title, id)` (empty or equal to id) and `getThreadDisplayTitle(thread)`.
   Files: `apps/web/src/constants/threads.ts`, `apps/web/src/lib/thread-title.ts` - Change: new constant and helper.
3. Code: `ThreadListItem` renders `getThreadDisplayTitle(thread)`.
   Files: `apps/web/src/components/chat/ThreadListItem.tsx` - Change: replace `thread.title || thread.id`.
4. Code: draft row is written with an empty title; the RUN_FINISHED gate and `hasGeneratedTitle` use `isPlaceholderTitle`.
   Files: `apps/web/src/hooks/use-draft-thread-row.ts`, `apps/web/src/hooks/use-thread-session.ts` - Change: as described.
5. Code: add `clearDraftThread(id)` to the draft store; in `use-thread-session` a timeout after RUN_FINISHED clears the draft when the cached list has no row for it.
   Files: `apps/web/src/store/draft-thread-store.ts`, `apps/web/src/hooks/use-thread-session.ts` - Change: new action and effect.
6. Code: rewrite the Mastra wording (`tripwire`, `generateTitle: false`) in the three files to describe the LangChain server.
   Files: `constants/threads.ts`, `hooks/use-draft-thread-row.ts`, `hooks/use-thread-session.ts` - Change: comments only.

## Done check
- `pnpm lint`, `pnpm typecheck` and `pnpm build` all exit 0 (no `pnpm test`: no runner)
- repro script prints "New chat" for the placeholder and the empty-title row, and the generated title for the control
- `grep -rniE "mastra|tripwire|generateTitle" apps/web/src` returns nothing
- Live app check if env allows (dev + AI servers on 5121 / 4121); otherwise state it was blocked

## Deviations
- Step 5: besides the new `clearDraftThread(id)` action and the timeout effect in `use-thread-session`, the existing "close the window" effect no longer calls `clearPendingTitle()` while the server list has no row for the thread. Without that, the effect cleared the pending window at the grace cut-off and cancelled the drop timeout before it fired. The timeout now clears both the draft (when still no row) and the pending window.
- Step 5: the delay (`THREAD_ROW_GRACE_MS + 2 * THREAD_TITLE_POLL_INTERVAL_MS`) is exported as `THREAD_DRAFT_DROP_MS` from `constants/threads.ts` (a file the Steps already name).
